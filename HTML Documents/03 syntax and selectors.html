Syntax and Selectors

Syntax Format

Syntax Example

Formula: selector → property → value
Example: p → color → blue

CSS Selectors

There are 4 ways to provide selectors: Universal, Element, Class, and ID.

1. Universal Selector *

The universal selector selects EVERYTHING.

Meaning: Everybody gets Arial. All elements get the font Arial, such as h1 to h6, p, and all text in the body. (This whole website uses it!)

2. Element Selector

The element selector uses an HTML tag.

Meaning: All paragraphs will become blue.

Meaning: All h1 will become red.

3. Class Selector .

A class allows us to give a special style to selected elements.

HTML:

CSS:

This is important.

This is normal.

This is also important.

Meaning: All elements with class="important" will become red.

4. ID Selector #

An ID identifies one specific element.

HTML:

CSS:

My Website (this one is purple)

Meaning: that specific element will become purple.

Selector Cheat Sheet

Selector Symbol Example
Universal * * { ... }
Element (tag name) p { ... }
Class . (dot) .important { ... }
ID # (hash) #title { ... }
Remember: . = CLASS and # = ID
