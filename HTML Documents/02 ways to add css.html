Ways to Add CSS

There are 3 ways to add CSS to a webpage: inline, internal, and external.

1. Inline CSS

Styles are coded right into the element's opening tag. You do not use selectors here.

This paragraph has blue text.

2. Internal CSS

Styles are placed at the top of the HTML page inside the style tag. They target elements using CSS selectors (like tags, classes, or IDs).

3. External CSS

This requires two separate files: an HTML file and a CSS file. This website uses external CSS (the file is css/styles.css).

styles.css (the stylesheet file)

index.html (the web page file)

Comparison

Type Where is it written? Uses selectors?
Inline Inside the tag (style="") No
Internal In the style tag at the top of the page Yes
External In a separate .css file Yes
